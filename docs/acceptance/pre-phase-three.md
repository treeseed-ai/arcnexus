# Pre-phase-three qualification

This gate covers readable configuration, enforceable component ownership, compact
TypeScript, mandatory initialization, task proposals and progress-driven execution.
TreeSeed retains its existing layout and is inspected through compatibility readers.
All live inference uses `gpt-6-luna` with medium reasoning; there is no Astra fallback.

All three live demonstrations passed. [PR #70](https://github.com/treeseed-ai/arcnexus/pull/70)
records final CI and staging integration. Simulated scenarios do not satisfy the live gate.
The [machine-readable index](pre-phase-three.json) hashes retained reports and artifacts.

terminate execution. Valid overlapping finite requests are queued and executed
sequentially with separate evidence.

## Retained failures and refinements

Each invocation retains its own supervisor, source revision, input/check hashes,
reports, SDK events and candidate. No campaign retries automatically and no failed
candidate implementation is silently copied into the development branch.

- `attempt-01`: report specification lacked an observed regression after choosing
  sandbox execution instead of its declared host operation. Workday request also
  paraphrased the captured contract. Required MCP startup, explicit route guidance
  and an exact contract response enum address those producer-side ambiguities.
- `attempt-02`: recipient planning indexed incoming-request criteria rather than
  its captured assignment. Prompts now put authoritative numbered criteria after
  inbox context. A separate dirty-source report invocation stopped before inference.
- `attempt-03`: intake reversed the request edge. The prompt now supplies eligible
  directed edges and distinguishes requesting consumer from supplying owner. Its
  report run ended before pending operation feedback arrived; `execution.wait` now
  waits for completion instead of repeated one-second observations.
- `attempt-05`: tests and lint were requested together. The former runtime rejected
  the overlap. Built-CLI coverage now proves serial execution, distinct logs and
  cancellation of queued work through the actual SDK/launcher/MCP path.

The protocol failures exposed gaps in deterministic scenario coverage, not a need
for larger worker models. The cheap regression is an actual bridge client issuing
requests before its previous operation completes; sequential fake replies cannot
exercise that lifecycle. Host checkpoints remain enforced throughout.

## Phase-three boundary

React should display YAML definitions, actual directory ownership, initialization
proposals, current commands, checklist revisions and host-verified evidence through
these same services. Elapsed time is not an ETA; agent checklist claims are not
host acceptance. The SDK exposes events and summaries, not private reasoning.

Advanced budgeting, automatic architecture acceptance, arbitrary teams, concurrent
execution and crash recovery remain later work. Caller integration remains explicit.
