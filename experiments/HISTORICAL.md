# Historical campaign inputs

Files ending in `.historical.yaml`, the `assignments/` and `workdays/` definitions,
and their report checkers retain earlier qualification intent. They can be inspected;
version-1/2 campaign execution is retired. Their fixed participants, caller-authored
acceptance and numeric limits do not configure current task/workday execution.

Active root manifests use version 3 and the shared task host. Bind a clean committed
project with execution defaults, eligible stewards and declared host checks. For the
three-owner example, materialize `fixtures/general` and use `general-live.yaml`.
A simulation binding must point to an explicitly scripted harness; simulation
results never establish live qualification. Old fault-injection/counter scenarios
are characterized by session tests and the shared scheduler/lifecycle matrix, not
an alternate executable workday engine.
